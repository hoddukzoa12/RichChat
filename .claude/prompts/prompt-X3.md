## 목표

**고객이 보낸 첨부를 화면에 꺼낸다.** `GET /api/attachments/:id`

`worker/routes/attachments.ts`가 지금 빈 스텁이다:

```ts
export const routes: Route[] = []
```

X2가 스키마·R2 바인딩·라우터 `:param` 지원을 깔아놨고, X4가 바이너리를 R2에
채운다. **여기는 꺼내는 쪽**이다.

## 왜 R2 공개 URL이 아닌가

고객이 보낸 것은 **사업자등록증·통장 사본·영수증**이다.
**링크만 알면 열리면 안 된다.**

그래서 동일 출처의 인증된 경로여야 한다. 세션 검사를 거치고, 응답이 공개
캐시에 들어가지 않아야 한다.

R2 서명 URL로 우회하지 마라 — 그것도 링크가 새면 열린다.

## 두 가지 모드

화면이 이미지를 **인라인으로** 렌더하고, **다운로드 버튼**도 따로 준다.

- 인라인 — 브라우저가 바로 표시
- 다운로드 — 파일로 저장

쿼리로 모드를 가르되 **기본값은 안전한 쪽**이어야 한다. 임의의 MIME을
인라인으로 렌더하면 저장된 HTML·SVG가 우리 출처에서 실행된다.

**신뢰할 수 있는 이미지 타입만 인라인**으로 허용하고 나머지는 다운로드로
강제해라. `mime_type`은 LGU+가 준 값이라 **믿을 수 없다** — 허용 목록으로 걸러라.

`X-Content-Type-Options: nosniff`를 붙여라.

## 한글 파일명

`Content-Disposition`에 한글을 그대로 넣으면 깨진다. **RFC 5987**
`filename*=UTF-8''<퍼센트인코딩>` 형식이 필요하다.

구형 클라이언트용 `filename=`도 함께 두되, 거기엔 ASCII 대체값을 넣어라.

파일명에 `"`·개행·경로 구분자가 들어오면 헤더가 깨지거나 주입된다.
**LGU+가 준 이름을 그대로 믿지 마라.**

## 상태를 구별해서 응답해라

`download_status`가 셋이다.

| 상태 | 응답 |
|---|---|
| `완료` | 바이트 |
| `대기` | **"아직 받는 중"임이 드러나게.** 없는 것과 달라야 한다 |
| `실패` | 실패임이 드러나게 |

**셋을 다 404로 뭉개지 마라.** 화면이 "받는 중"과 "없음"을 구별해 보여줘야
한다 (F4가 그렇게 그린다).

`완료`인데 R2에 객체가 없으면 그것도 구별해 알려라 — 그건 X4의 결함 신호다.

## 반드시 지킬 것

### 스코프

`officeId`는 **세션에서** 온다. 첨부 조회에 그 조건을 걸어라.
쿼리나 경로에서 사무소를 받지 마라.

### 캐시

**공개 캐시에 들어가면 안 된다.** 인증이 걸린 개인 문서다.
`Cache-Control`을 `private`으로 두고, CDN이 공유하지 않게 해라.

### 메모리

`await res.arrayBuffer()`로 전체를 올리지 마라. R2 객체의 body를 스트림으로
그대로 넘겨라. 큰 첨부에서 isolate가 죽는다.

`Content-Length`를 알 수 있으면 실어라.

### Range 요청

동영상·큰 파일에 브라우저가 `Range`를 보낼 수 있다. 지원할지는 **네가
판단해라** — 지원하지 않는다면 그 사실이 응답에서 분명해야 한다.
잘못된 부분 응답을 주는 것보다 지원 안 함이 낫다.

### 존재하지 않는 id

404. **어떤 이유로 없는지 구분해 알리지 마라** — 남의 사무소 첨부인지
아예 없는지가 새면 안 된다.

## 수용 기준

1. `npm run check` 통과
2. **세션 없이 → 401**
3. 다른 사무소의 첨부 id → 404 (내용이 새지 않는다)
4. 없는 id → 404, 위와 **구별되지 않는다**
5. `완료` 첨부 → 바이트가 나온다
6. **`대기` 첨부 → "받는 중"이 드러난다. 없음과 구별된다**
7. `실패` 첨부 → 실패가 드러난다
8. **한글 파일명이 온전하다** — RFC 5987. 실제로 다운로드해 이름을 확인해라
9. 파일명에 `"`·개행이 들어와도 헤더가 깨지지 않는다
10. **허용 목록 밖 MIME은 인라인으로 나가지 않는다.**
    HTML·SVG를 저장해 시도해봐라
11. `X-Content-Type-Options: nosniff`가 있다
12. **`Cache-Control`이 공개 캐시를 막는다**
13. 응답 전체가 메모리에 올라가지 않는다
14. `완료`인데 R2 객체가 없으면 구별되는 응답
