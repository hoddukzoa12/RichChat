## 목표

**새 메시지가 실제로 도착하면 화면이 바뀐다.**

지금은 `setTimeout(3500)` 목업이 새 메시지 도착을 흉내낸다. 그걸 지우고
서버 이벤트로 바꾼다.

- 캐치업 (B20) — `GET /api/events?since=<officeSeq>`
- WebSocket (B21) — `GET /api/realtime`

## 순서가 중요하다 — 폴링 먼저, 소켓 나중

**정합 로직을 먼저 세우고 WebSocket을 그 뒤에 끼워 넣어라.**

1. `GET /api/events?since=` 폴링으로 **먼저 동작하게** 한다
   (활성 탭 5초 / 숨김 30초)
2. 같은 정합 코드 경로에 WebSocket을 **덧붙인다**

이유는 둘이다. WebSocket이 죽어도 앱이 돌아가고, 정합 로직을 소켓 없이
증명할 수 있다. **소켓을 먼저 붙이면 "가끔 안 맞는다"를 디버깅하게 된다.**

## 갭 감지가 이 슬라이스의 본질이다

무상태 팬아웃은 프레임을 조용히 흘린다 (isolate 축출, 버퍼 포화, 재접속 중).
**D1은 안 틀리지만 브라우저가 틀린 채로 남는다.**

그래서 모든 이벤트에 `officeSeq`가 실려 온다.

```
받은 officeSeq === lastSeq + 1  → 적용
그 외                            → 갭. GET /api/events?since=lastSeq 로 따라잡는다
```

**연속이 아니면 적용하지 마라.** 순서가 뒤바뀐 프레임을 그냥 적용하면
화면이 조용히 어긋난다.

`lastSeq`를 **적용에 성공한 뒤에만** 전진시켜라.

### 재접속·탭 복귀 시엔 항상 캐치업이 먼저다

DO는 히스토리를 주지 않는다. 소켓이 다시 붙었다고 최신인 게 아니다.
**연결 직후, 탭이 다시 보일 때, 네트워크가 돌아왔을 때 — 전부 캐치업부터.**

### 410은 "전부 다시 받아라"다

커서가 너무 오래돼 잘렸거나 `since`가 서버보다 크면 서버가 410을 준다.
**조용히 넘기지 마라** — 목록·스레드를 다시 불러와 처음부터 맞춰라.

## 낙관적 갱신과 충돌하지 않게

F4가 발송에 `clientKey`를 싣고 서버가 그대로 돌려준다. 실시간 이벤트로도
같은 메시지가 온다.

리듀서가 **`clientKey` 먼저, 없으면 `id`로** 병합하므로 중복 말풍선이
생기지 않는다. **그 규칙을 우회하는 경로를 만들지 마라** — 이벤트를 별도
경로로 밀어 넣으면 같은 메시지가 두 번 그려진다.

## 목업 제거

`grep -c 3500 src/`가 0이어야 한다. 타이머로 상태를 바꾸는 코드를 전부 지워라.

## 반드시 지킬 것

### 소켓은 URL에 토큰을 싣지 않는다

동일 출처 업그레이드라 쿠키가 자동으로 간다. **URL에 넣으면 Referer·프록시
로그·브라우저 히스토리에 남는다.**

### 재연결

끊기면 지수 백오프로 다시 붙어라. **즉시 무한 재시도하지 마라** — 서버가
내려간 동안 브라우저가 요청을 쏟아붓는다.

재연결마다 캐치업이 먼저다.

### 숨은 탭

`document.hidden`일 때 폴링 주기를 늘려라. 소켓은 유지하되 **핑으로 서버
하이버네이션을 깨우지 마라** — 서버가 자동 응답을 설정해 뒀다.

### 정리

언마운트·로그아웃 시 소켓과 타이머를 **반드시 정리해라.** 남으면 로그아웃
후에도 요청이 나가고 401이 쌓인다.

## 수용 기준

1. `npm run check` 통과
2. **앱이 실제로 뜬다.** 두 브라우저를 열어 한쪽에서 보내고 다른 쪽 반영을 봐라
3. **`grep -c 3500 src/` = 0**
4. **폴링만으로 동작한다** — WebSocket을 막아도 화면이 갱신된다
5. **갭 감지가 실제로 작동한다.** `officeSeq`를 건너뛴 프레임을 주면
   적용하지 않고 캐치업한다
6. `lastSeq`가 적용 성공 후에만 전진한다
7. **재접속 시 캐치업이 먼저** 일어난다
8. 탭을 숨겼다 되돌리면 놓친 변경이 반영된다
9. **410 → 전체 재동기화.** 조용히 넘어가지 않는다
10. 내가 보낸 메시지가 실시간 이벤트로도 와서 **말풍선이 두 개 되지 않는다**
11. URL·쿼리에 토큰이 없다
12. 로그아웃 후 소켓·타이머가 정리된다 (요청이 더 안 나간다)
13. 서버를 내렸다 올리면 백오프로 재연결하고 동기화된다
