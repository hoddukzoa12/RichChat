## 목표

LGU+ 메시지허브 API를 호출하기 위한 **토큰 획득 층**을 만든다.
발송·수신·리포트 슬라이스가 전부 여기를 통과한다.

`worker/lgu/` 안에만 만든다. 라우트나 도메인 로직은 건드리지 않는다.

## 왜 이게 까다로운가

액세스 토큰은 **1시간짜리 공유 자원**이다. Worker isolate는 여러 개가 동시에
돌고 수시로 교체된다. 그대로 두면 isolate마다 따로 재인증해서 **인증
엔드포인트에 스탬피드**가 생긴다.

그리고 **리프레시를 쓸 수 없다.** 리프레시 토큰이 발급 IP에 묶여 있는데
Workers는 고정 egress IP를 보장하지 않는다. 다른 colo에서 호출하면 간헐적으로
실패하고, 원인 찾기가 매우 어려운 버그가 된다.

→ **refresh 엔드포인트를 절대 호출하지 마라.** 만료 전에 재인증한다.

## 만들 것

### 토큰 획득

대략 이런 흐름이다. 세부는 네가 정해라.

```
1. isolate 메모리 캐시 — 만료까지 여유가 있으면 그대로 반환
2. lgu_tokens 조회 — 유효하면 캐시하고 반환
3. 리스 획득 (아래) — 못 얻으면 잠깐 기다렸다 2로
4. 재인증 → 저장 → 반환
```

**리스로 리더를 뽑는다.** Durable Object를 쓰지 마라 — 토큰은 isolate 교체를
넘겨 살아남아야 하고, DO에 두면 "DO는 정본을 갖지 않는다"는 이 프로젝트의
불변식이 깨진다. `lgu_tokens.lease_until`이 그 용도로 이미 스키마에 있다.

조건부 UPDATE로 경합을 해소해라 — `meta.changes`가 1이면 내가 리더다.
`worker/db/`의 헬퍼를 써라.

만료 시각은 **실제 만료보다 여유 있게** 잡아라. 정확히 60분으로 두면 경계에서
만료된 토큰으로 호출하게 된다.

### 인증 요청

```
POST https://{인증호스트}/auth/v1/{randomStr}
{ "apiKey": "...", "apiPwd": "..." }
```

`randomStr`은 요청마다 새로 만드는 임의 문자열이다(영문·숫자·하이픈·언더스코어,
20자 이하).

**`apiPwd` 계산이 함정이다:**

```
apiPwd = base64( SHA512( base64(SHA512(비밀번호)) + "." + randomStr ) )
```

두 해시 모두 **raw 64바이트 다이제스트의 base64**다. hex 문자열을 base64한 게
아니다. 여기서 틀리면 인증이 조용히 실패한다.

### 설정과 비밀

호스트는 `wrangler.jsonc`의 변수로 가른다. **코드에 분기를 넣지 마라.**
지금은 검수(QA) 환경을 쓴다:

- 인증: `api.msghub-qa.uplus.co.kr`
- 발송: `api-send.msghub-qa.uplus.co.kr`
- 컨텐츠 관리: `mnt-api.msghub-qa.uplus.co.kr` (호스트가 셋이다)

`apiKey`와 비밀번호는 **`wrangler secret`으로 관리**한다. 설정 파일이나 소스에
넣지 마라. 지금 실제 값이 없으므로 **바인딩만 선언하고 없으면 명확히 실패**하게
해라 — 조용히 빈 문자열로 진행하면 나중에 원인을 못 찾는다.

`wrangler.jsonc`에 변수·시크릿 바인딩을 추가하고 `npm run types`로
`worker-configuration.d.ts`를 재생성해 커밋에 포함해라. `types:check`가
`npm run check`에 물려 있어 안 하면 게이트가 막는다.

### HTTP 층

`worker/lgu/http.ts`에 공통 호출 헬퍼를 둬라. 이후 슬라이스가 발송·리포트·
컨텐츠 업로드에 재사용한다.

- 토큰을 자동으로 붙인다 (`Authorization: Bearer`)
- LGU+ 응답의 `code`가 성공이 아니면 **명확한 오류**로 바꾼다.
  응답 본문을 삼키지 마라 — 원인 코드가 디버깅의 전부다
- 네트워크 오류와 API 오류를 구분할 수 있게 해라

**떠다니는 Promise를 만들지 마라.** 모든 Promise는 await하거나 반환하거나
`ctx.waitUntil()`에 넘겨야 한다.

## 테스트

실제 LGU+를 호출하지 마라. HTTP 층을 갈아끼울 수 있게 만들고 가짜로 검증해라.

## 수용 기준

1. `npm run check` 통과
2. **`apiPwd` 해시가 맞다** — 알려진 입력에 대한 기대값을 테스트로 고정.
   base64(raw digest)이지 base64(hex)가 아님을 구분하는 케이스를 넣어라
3. **동시에 10번 호출해도 인증 요청은 1회** — 나머지는 그 결과를 쓴다
4. 캐시된 토큰이 유효하면 D1 조회도 인증 호출도 하지 않는다
5. 만료가 임박하면 재인증한다 (경계를 테스트로 명시)
6. **`grep -rc "refresh" worker/lgu/` → 0**
7. 시크릿이 없으면 **명확한 오류**로 실패한다 (빈 문자열로 진행하지 않음)
8. LGU+가 실패 코드를 주면 그 코드가 오류에 실려 나온다
9. 호스트가 코드가 아니라 설정에서 온다
