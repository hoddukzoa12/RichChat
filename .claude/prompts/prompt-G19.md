# G19 — 데스크톱 알림 배선

`AGENTS.md`를 먼저 읽고 그 원칙을 따라라.

## 지금 상태

설정 화면에 알림 토글 3개(`notifyNewChat`·`notifyMineOnly`·`notifySound`)가
있고 `user_settings`에 저장까지 되는데, **그 값을 읽어 알림을 울리는 코드가
0곳이다.** 화면이 "데스크톱 알림에 소리를 함께 재생합니다"라고 약속하는데
어떤 경우에도 알림이 뜨지 않는다. 이 배선이 이 슬라이스다.

**프론트 전용이다.** 서버는 설정 API와 실시간 이벤트를 이미 제공한다 —
`worker/`를 건드릴 일이 없다.

## 동작 규칙 (사용자 승인된 설계)

수신 메시지가 실시간 경로(소켓·폴링)로 도착하면:

| 조건 | 동작 |
|---|---|
| 발신(direction='out') | 알리지 않음 |
| **지금 화면에 보이는 그 대화**의 메시지 (탭 포커스 + 해당 대화 열림) | 알리지 않음 |
| `notifyMineOnly` 켜짐 + 내 담당 아닌 대화 | 알리지 않음 |
| 그 외 수신 | **데스크톱 알림** (`Notification` API) |
| `notifySound` 켜짐 | 알림과 함께 짧은 소리 |

- 알림 내용: 고객 표시명 + 본문 미리보기. **마스킹 규칙은 화면과 같게** —
  목록 미리보기가 쓰는 기존 함수를 재사용해라. 새로 만들면 SSOT 위반이다
- **알림 클릭 → 창 포커스 + 그 대화 열기**
- `notifyNewChat`의 의미는 설정 화면 문구와 원본 디자인
  (`design/prototype.dc.html`)을 확인해 정하고, 판단이 갈리면 `ask`로 물어라

## 함정 — 각각 수용 기준에 있다

1. **권한.** `Notification.requestPermission()`은 사용자 제스처에서만
   의미가 있다 — 토글을 켜는 순간 요청해라. 거부 상태면 설정 화면에
   "브라우저에서 차단됨"을 보여주고 토글이 거짓 약속을 하지 않게 해라
2. **캐치업 재생.** 폴링이 밀린 메시지를 한꺼번에 가져올 때(서버 중단 후
   재개, 숨긴 탭 복귀) 과거 메시지로 알림이 연발되면 안 된다. 처음 로드와
   캐치업 분량은 알리지 말고, **연결 이후 새로 도착한 것만** 알려라.
   메시지 ID 멱등으로 중복도 막아라
3. **소리 파일은 번들에 포함해라.** 외부 CDN 로드 금지. 브라우저 자동재생
   정책상 상호작용 전에는 소리가 막힐 수 있다 — 실패해도 조용히 넘어가고
   콘솔 오류를 남기지 마라
4. **여러 탭.** 같은 계정이 탭 둘을 열면 알림이 두 번 뜬다.
   `BroadcastChannel` 등으로 하나만 울리게 하되, 복잡해지면 **중복을 감수하고
   그 사실을 주석에 남기는 쪽을 택해도 된다** — 사무소 하나짜리 도구다.
   어느 쪽이든 판단 근거를 적어라

## 건드리지 마라

`worker/`, `shared/`(타입 추가가 필요하면 `ask`), `migrations/`.
**`AGENTS.md`·`CLAUDE.md`·계획서 수정 금지.**

## 수용 기준

부품이 아니라 **끝에서 끝까지** 확인해라.

1. `npm run check` 통과 (DOM 테스트 포함)
2. **실제 브라우저에서**: 다른 대화를 보는 중 수신 → 알림이 뜨고, 클릭하면
   그 대화가 열린다
3. 보고 있는 대화의 수신은 알림이 없다
4. `notifyMineOnly`·`notifySound` 토글이 실제 동작을 바꾼다
5. 권한 거부 상태에서 설정 화면이 차단됨을 보여준다
6. **서버 12초 중단 후 재개**(기존 검증 시나리오)에서 캐치업 분량으로 알림이
   연발되지 않는다
7. 알림 문구의 전화번호 마스킹이 화면과 같다
8. `python3 .claude/scripts/dead-exports.py` · `positional-consts.py` ·
   `unwired-routes.py` 통과
9. 커밋하고 `origin/hoddukzoa12/g19-desktop-notifications`에 푸시한 뒤 해시를
   보고해라. **배포하지 마라.**
