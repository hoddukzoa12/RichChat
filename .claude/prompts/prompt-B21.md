## 목표

**직원 브라우저에 변경을 실시간으로 밀어준다.** `GET /api/realtime` (WebSocket)

사무소당 Durable Object 하나(`OfficeHub`)가 팬아웃만 한다.

## Durable Object는 정본을 갖지 않는다

**이게 이 슬라이스에서 가장 중요한 제약이다.**

DO에 상태를 저장하는 순간 D1과 두 개의 진실이 생긴다. 그러면 "어느 쪽이 맞나"를
매번 판단해야 하고, 그 판단이 틀리는 날 데이터가 갈라진다.

- **`ctx.storage`를 쓰지 마라.** `grep -c storage`가 0이어야 한다
- 이벤트 히스토리를 DO가 보관하지 마라 — 캐치업은 `GET /api/events`(B20)가 한다
- DO가 D1에 쓰지 마라. 읽기도 하지 마라
- 알람을 걸지 마라

DO는 **연결 목록을 들고 프레임을 뿌리는 것**만 한다. 죽어도 D1은 안 틀리고,
클라이언트는 재접속해서 캐치업한다.

## 브로드캐스트는 잃어도 된다 — 그게 설계다

무상태 팬아웃은 프레임을 조용히 흘릴 수 있다 (isolate 축출, 버퍼 포화, 재접속 중).
**D1은 안 틀리지만 브라우저가 틀린 채로 남는다.**

그래서 모든 이벤트에 **사무소 내 연속 번호**(`office_seq`)를 싣는다.
클라이언트가 `lastSeq + 1`이 아니면 갭을 감지하고 HTTP로 따라잡는다.

**브로드캐스트 실패가 D1 커밋을 되돌리면 안 된다.** 발행은
`ctx.waitUntil(hub.broadcast(...))`로 커밋 **후에** 한다. 실패해도 이벤트 행은
D1에 있으므로 캐치업이 해결한다.

## 봉투는 하나다 — 새로 정의하지 마라

WS 프레임과 `GET /api/events`의 행이 **같은 타입**을 쓴다.

`shared/wire/event.ts`가 **B20 소유이고 이미 정의돼 있다.** 그것을 import 해라.
**직접 정의하지 마라** — 두 벌이 되면 경로에 따라 클라이언트가 다르게 동작한다.

모양이 부족하면 구현하지 말고 `ask`로 물어라.

## 반드시 지킬 것

### 인증 — 업그레이드에서 검증한다

동일 출처 업그레이드라 **쿠키가 자동으로 실려 간다. URL에 토큰을 넣지 마라** —
Referer·프록시 로그·브라우저 히스토리에 남는다.

Worker가 `requireSession`으로 검증한 뒤 DO로 넘긴다. **DO가 인증을 다시 하지
않게 하되, DO에 넘어가는 것이 이미 검증된 신원인지 분명해야 한다.**

쿠키 없는 업그레이드 → 401.

### 하이버네이션

`ctx.acceptWebSocket()`을 써라. 표준 `server.accept()`를 쓰면 연결이 살아 있는
동안 DO가 메모리에 상주해 비용이 계속 나간다.

`serializeAttachment()`로 연결에 신원을 붙여라 — 하이버네이션에서 깨어날 때
그게 없으면 누구 연결인지 모른다.

`setWebSocketAutoResponse()`로 핑을 처리해라. 핑마다 깨우면 하이버네이션이
무의미하다.

### 사무소 스코프

DO 인스턴스는 **사무소당 하나**다. `idFromName`/`getByName`으로 결정적으로
라우팅해라. 전역 DO 하나에 전부 붙이면 병목이고, 연결마다 만들면 팬아웃이 안 된다.

`officeId`는 **세션에서** 온다.

### 연결 정리

닫힌 연결에 계속 쓰면 오류가 쌓인다. `webSocketClose`·`webSocketError`에서
목록을 정리해라.

**한 연결이 실패해도 나머지 브로드캐스트가 멈추면 안 된다.**

### 설정

`wrangler.jsonc`에 `OFFICE_HUB` 바인딩이 **B0에서 이미 선언돼 있다.**
migrations 항목(`new_sqlite_classes`)이 필요한지 확인하고, 필요하면
**그것만** 추가해라.

## 수용 기준

1. `npm run check` 통과
2. **쿠키 없는 업그레이드 → 401**
3. 같은 사무소의 소켓 2개가 **동시에** 같은 이벤트를 받는다
4. **`grep -c storage worker/realtime/hub.ts` = 0**
5. DO가 D1에 접근하지 않는다
6. 프레임의 `officeSeq`가 연속이고 `GET /api/events`의 값과 **일치한다**
7. 봉투 타입이 `shared/wire/event.ts`에서 온다. 중복 정의 0건
8. **브로드캐스트가 실패해도 D1 이벤트 행은 남는다.**
   실제로 실패시켜 확인해라 — 이게 갭 복구의 전제다
9. 한 연결이 끊겨도 다른 연결이 계속 받는다
10. `ctx.acceptWebSocket`을 쓴다 (`server.accept()` 아님)
11. 닫힌 연결이 목록에서 제거된다
12. URL·쿼리에 토큰이 실리지 않는다
