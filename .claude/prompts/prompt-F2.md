## 역할

너는 RichChat 저장소의 슬라이스 F2를 구현한다. 다른 슬라이스는 건드리지 않는다.

**시작 전에 저장소 루트의 `AGENTS.md`를 읽고 그대로 따른다.**

## 배경 — 지금 무엇이 틀렸는가

세무사무소 상담 인박스다. 지금 프론트엔드는 **시각을 포맷된 한국어 문자열로
저장하고 있다.**

```ts
// src/data/seed.ts
time: '2분 전'          // 데이터가 아니라 화면 문구다
time: '오후 2:06'
// src/state/inbox.ts — 메시지를 보내면
time: '방금'            // 한 번 쓰이고 영원히 갱신되지 않는다
```

그래서 한 시간 전에 보낸 메시지가 **영원히 "방금"으로 보인다.** 정렬도 안 되고
시간대도 불명이다. 백엔드는 앞으로 epoch 밀리초 정수만 준다.

## 목표

`src/lib/time.ts` 하나와 그 테스트. **순수 함수만** 만든다.

epoch 밀리초를 받아 화면 문구를 만드는 함수들이다. 최소한 이 둘이 필요하다:

- **상대 시각** — 목록의 `2분 전`, `1시간 전`, `어제`, 그리고 아주 최근이면 `방금`
- **절대 시각** — 말풍선의 `오후 2:06`, 날짜 구분선의 `2026년 7월 28일`

경계(몇 초까지 '방금'인지, 며칠부터 날짜로 바뀌는지)는 네가 정하되,
**테스트로 경계를 명시해라.** 나중에 누가 바꿀 때 근거가 남는다.

## 반드시 지킬 것

- **KST 고정.** 브라우저 시간대를 따라가면 안 된다. 세무사무소 직원과 고객이
  전부 한국에 있고, 서버는 UTC다. 시간대가 흔들리면 "어제 온 문의"가
  사람마다 다르게 보인다.
- **`now`를 주입받아라.** `Date.now()`를 함수 안에서 직접 부르면 테스트가
  현재 시각에 의존해 불안정해진다. 기본값으로 `Date.now()`를 쓰되 인자로
  덮어쓸 수 있게 한다.
- **순수 함수만.** React 훅이나 타이머는 이 슬라이스에 넣지 않는다.
  주기적 갱신은 화면을 그리는 슬라이스가 담당한다 (`AGENTS.md` §3 모듈 경계 —
  `src/lib/`는 표현이 아니다).

## 수용 기준

1. `npm run check` 통과
2. `now`를 주입해 경계값을 검증하는 테스트 — 최소 6케이스
   (방금 / 분 / 시간 / 어제 / 며칠 전 / 오전·오후 전환)
3. **시간대 고정 증명** — 프로세스 `TZ`를 바꿔도(예: `TZ=UTC`, `TZ=America/New_York`)
   같은 입력이 같은 문자열을 내는 테스트
4. `Date.now()`가 함수 본문에서 직접 호출되지 않고 기본 인자로만 쓰인다
5. **변경 파일이 `src/lib/time.ts`와 그 테스트 파일 둘뿐** —
   `git diff --name-only main..HEAD`로 증명
6. React import가 없다

## 건드리지 말 것

- `src/` 아래 위 두 파일을 제외한 **모든 것.** 특히 `src/state/inbox.ts`,
  `src/data/seed.ts`, `src/components/` — 아직 이 함수를 쓰지 않는다.
  사용처 연결은 나중 슬라이스가 한다
- `worker/`, `shared/`, `migrations/`
- `AGENTS.md`, `CLAUDE.md`, `wrangler.jsonc`, `design/`, `.claude/`, `.mcp.json`

기존 문자열을 이 함수로 바꾸고 싶은 충동이 들 텐데 **하지 마라.** 지금 바꾸면
목 데이터가 깨지고 다른 슬라이스와 충돌한다.

## 완료 보고

`worker_done`으로 보고한다.

설계가 이상하다고 판단되면 구현하지 말고 `ask`로 물어라.
