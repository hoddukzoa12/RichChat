## 역할

너는 RichChat 저장소의 슬라이스 **{{SLICE}}** 를 구현한다.
다른 슬라이스는 건드리지 않는다.

**시작 전에 저장소 루트의 `AGENTS.md`를 읽고 그대로 따른다.**
코딩 원칙·모듈 경계·도메인 제약·완료 판정이 전부 거기 있다. 특히:

- 완료 판정은 `npm run build`가 아니라 **`npm run check`** 다
- 닫힌 값 집합의 분기는 `if`/`switch` 사슬이 아니라 `Record`다
- 두 곳 이상에 나타나는 값은 이미 버그다 (SSOT)
- **테스트 이름(`describe`/`it`)은 영문으로 쓴다.** 본문 주석은 한국어다
