## 목표

대화 **상세**와 **메시지 페이지** 두 엔드포인트.

```
GET /api/conversations/:id
GET /api/conversations/:id/messages?before=<커서>&limit=50
```

지금 프론트엔드는 대화 객체 안에 모든 메시지를 통째로 들고 있다. 스레드를
열려고 전체 이력을 받는 구조를 끊는 것이 이 슬라이스다.

## 상세에 담길 것

고객 카드(이름·상호·직함·전화·커스텀 필드), 담당자 목록, 업무, 메모,
상태·라벨·보관 여부, 그리고 **낙관적 잠금용 `version`**.

`shared/wire/conversation.ts`에 모양을 정의해라. 목록 API(B6)가 같은 파일을
쓰지만 **다른 타입**이다 — 목록 항목과 상세를 한 타입으로 합치지 마라.
합치면 목록이 상세만큼 무거워지거나 상세에 없는 필드가 생긴다.

## 반드시 지킬 것

### 발신자 — 지금 가장 크게 틀린 곳

프로토타입은 발신 말풍선에 **보고 있는 사람의 이니셜**을 렌더한다. 어제 김세무가
보낸 답장을 박상담이 열면 박상담이 보낸 것처럼 보인다. 이력이 통째로 거짓이다.

**모든 메시지에 발신자 정보가 실려야 한다.** `messages.sender_user_id`를
`users`에 조인해서 이름·직함을 내려라. 인바운드는 발신자가 없다 (고객이
사무소 번호로 보낸 것이라 개인 식별이 안 된다) — 그 사실이 응답에서
명확해야 한다.

**이니셜은 내려보내지 마라.** `shared/text.ts`의 `initialOf()`로 클라이언트가
파생한다. 저장도 전송도 하지 않는다.

### 메시지 페이지 — 과거로 거슬러 올라간다

스레드는 **최신이 아래**고 위로 스크롤하며 과거를 불러온다. 목록(B6)과 방향이
반대다.

`(occurred_at, id)` 복합 키로 **역방향 키셋 커서**를 써라. `ix_msg_thread`
인덱스가 `(conversation_id, occurred_at, id)`로 이미 있다.

`OFFSET`을 쓰지 마라 — 위로 읽는 동안 아래에 새 메시지가 들어오면 밀린다.

응답은 **시간 오름차순**으로 정렬해서 내려라. 클라이언트가 다시 뒤집게 하지 마라.

### 첨부

`message_attachments` 테이블이 이미 있다 (X2). 메시지 응답에 첨부 메타데이터를
실어라 — 파일명·크기·MIME·다운로드 상태.

**바이너리나 R2 키를 응답에 넣지 마라.** 클라이언트는 `/api/attachments/:id`로
가져간다 (X3 소유, 아직 스텁이다). `shared/wire/message.ts`에 첨부 타입이
이미 정의돼 있으니 **그대로 써라.**

`download_status`가 아직 완료가 아닌 첨부는 그 사실이 응답에 드러나야 한다.
클라이언트가 "받는 중"을 표시해야 하기 때문이다.

### N+1을 만들지 마라

메시지 50건에 발신자 조회 50번, 첨부 조회 50번이 되면 안 된다. 조인하거나
`IN` 한 번으로 묶어라. **쿼리 수가 메시지 수에 비례하면 실패다.**

### 없는 id

존재하지 않는 대화 → 404. **어떤 이유로 없는지 구분해 알리지 마라.**

## 수용 기준

1. `npm run check` 통과
2. 쿠키 없이 호출 → 401
3. **모든 발신 메시지에 발신자 이름이 있다.** 사용자 A가 보낸 메시지를
   사용자 B가 조회해도 발신자는 A다 (지금 결함의 직접 반례)
4. 인바운드 메시지는 발신자가 없고, 그게 응답에서 명확하다
5. 커서로 두 페이지를 거슬러 올라갔을 때 **중복·누락 0**
6. 페이지 사이에 새 메시지가 도착해도 **과거 페이지가 어긋나지 않는다**
7. 응답 메시지가 **시간 오름차순**
8. 첨부가 있는 메시지 → 메타데이터가 실리고 **R2 키·바이너리는 없다**
9. 다운로드 미완료 첨부가 그 상태로 구분된다
10. 없는 대화 id → 404
11. **쿼리 수가 메시지 수에 비례하지 않는다** — 메시지 200건을 넣고 확인해라
12. `EXPLAIN QUERY PLAN`이 `ix_msg_thread`를 쓴다

- 첨부 서빙 (`worker/routes/attachments.ts`) — X3 소유. 스텁 그대로 둬라
- 프론트엔드(`src/`), `migrations/`, `wrangler.jsonc` 수정
