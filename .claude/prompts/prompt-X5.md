## 목표

**시크릿·변수 템플릿 파일을 만든다.** `.dev.vars.example`

배포하는 사람이 "이 값을 어디서 구하나"를 알 수 없는 상태다. 특히
`LGU_MO_WEBHOOK_SECRET`은 이름 때문에 **LGU+가 발급하는 값처럼 읽히는데
실제로는 우리가 생성해서 LGU+ 콘솔에 등록하는 값**이다.

## 왜 `.dev.vars.example`인가

이 프로젝트는 로컬에서 `.dev.vars`를 읽는다 (Cloudflare Workers 규약).
`.env`는 **아무것도 읽지 않는다.** 그러니 복사해서 바로 쓸 수 있는 이름이어야 한다.

## `.gitignore`를 먼저 고쳐라

지금 `.gitignore:4`가 `.dev.vars*`라 **예시 파일까지 무시된다.**
예외를 넣어라:

```
.dev.vars*
!.dev.vars.example
```

**순서가 중요하다** — 부정 패턴이 뒤에 와야 한다. 넣은 뒤
`git check-ignore -v .dev.vars.example`로 확인해라. 아무것도 안 나와야 한다.
그리고 `.dev.vars` 자체는 **여전히 무시되는지** 같이 확인해라.

## 파일 내용

각 항목에 **한국어 주석**으로 세 가지를 적어라:

1. **누가 발급하는가** — 우리가 생성 / LGU+ / 네이버웍스
2. **어디서 구하는가** — 콘솔 경로나 생성 명령
3. **없으면 무엇이 안 되는가**

값은 **전부 비워두거나 명백한 자리표시자**로 둬라. **실제 시크릿을 넣지 마라.**

### 담을 항목

`wrangler.jsonc`의 `secrets.required` 5개와 `vars` 중 배포 시 채워야 하는 것들이다.
**직접 읽어서 목록을 맞춰라** — 내가 여기 옮겨 적으면 나중에 어긋난다.

특히 이 셋은 성격이 다르니 주석에서 분명히 갈라라:

- **우리가 생성** — MO·리포트 웹훅 시크릿.
  생성 명령을 주석에 적어라 (`openssl rand -base64 32 | tr '+/' '-_' | tr -d '='` 같은
  URL 안전한 방식). URL 경로에 들어가므로 URL 안전 문자만 써야 한다.
  **LGU+ 관리자콘솔에 등록할 전체 URL 형태**도 예시로 적어라:
  `https://<도메인>/api/hooks/lgu/mo/<생성한값>`
- **LGU+ 발급** — `LGU_API_KEY`·`LGU_API_PASSWORD`
- **네이버웍스 발급** — `WORKS_CLIENT_ID`·`WORKS_CLIENT_SECRET`·`WORKS_TENANT_ID`

`DEV_LOGIN_ENABLED`는 **운영에서 절대 `true`가 되면 안 된다**는 경고를 달아라.
정확히 `'true'`일 때만 열리고 그 외에는 닫힌다는 것도 적어라.

### 파일 상단에 적을 것

- 이 파일을 `.dev.vars`로 복사해 로컬에서 쓴다
- **운영 배포는 이 파일이 아니라 `wrangler secret put <이름>`으로 넣는다.**
  `vars`는 대시보드에 평문으로 보이므로 시크릿을 거기 두지 마라
- **웹훅 시크릿은 회전하려면 LGU+ 콘솔의 URL도 함께 바꿔야** 하고,
  그 사이 수신이 끊긴다

## 반드시 지킬 것

**실제 시크릿 값을 커밋하지 마라.** 작업 후 `git diff`로 자리표시자만
들어갔는지 직접 확인해라.

`.dev.vars`(실제 파일)를 건드리지 마라. 이미 로컬 값이 들어 있다.

`wrangler.jsonc`를 수정하지 마라. 이 슬라이스는 문서만 만든다.

## 수용 기준

1. `npm run check` 통과 (398개 그대로)
2. `.dev.vars.example`이 **git에 추적된다** — `git check-ignore -v` 출력 없음
3. **`.dev.vars`는 여전히 무시된다**
4. `secrets.required`의 5개가 **전부** 파일에 있다
5. 배포 시 채워야 하는 `vars`도 있다
6. 각 항목에 **누가 발급하는지**가 한국어로 적혀 있다
7. 웹훅 시크릿에 **생성 명령**과 **등록할 URL 형태**가 있다
8. `DEV_LOGIN_ENABLED` 경고가 있다
9. **실제 시크릿 값이 하나도 없다** — 자리표시자뿐
10. 파일을 `.dev.vars`로 복사하면 **로컬 개발이 뜬다**
    (자리표시자 상태에서도 서버가 기동하는지 확인해라)
